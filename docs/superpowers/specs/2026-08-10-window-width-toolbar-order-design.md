# WEditor 窗口默认宽度与左侧工具栏按钮顺序调整 — 设计

日期：2026-08-10
状态：已批准

## 背景

用户反馈两个 UI 调整诉求：

1. **窗口默认宽度不够**：启动后默认 1200px 宽，左右分栏（编辑 + 预览）显得局促，希望默认更宽。
2. **左侧竖排工具栏中"设置"按钮位置**：希望放到工具栏最底部（最后一个）。

## 目标

- 默认窗口宽度由 `1200` 调整为 `1440`（高度、最小尺寸不变），让左右分栏更宽松。
- 左侧竖排工具栏按钮顺序由
  `视图切换 → 设置 → 语法指南 → 复制格式 → 语言 → 关于`
  调整为
  `视图切换 → 语法指南 → 复制格式 → 语言 → 关于 → 设置`。

## 方案（已选：直接调整）

| 文件 | 改动 |
|------|------|
| `main.go` | `options.App.Width` 由 `1200` 改为 `1440`（`Height: 768`、`MinWidth: 800`、`MinHeight: 500` 保持不变） |
| `frontend/src/components/layout/AppHeader.vue` | 将"设置"按钮的 `<button>` 模板块从 `header-right` 第 2 位移至末尾；`toggle-settings` 事件、齿轮图标、`active` 高亮、`showSettingsPanel` 绑定均不变 |

### 明确不做

- 不改 `viewMode` 默认值（仍为 `both` 左右分栏）。
- 不改窗口高度、最小尺寸。
- 不改其它按钮（语法指南/复制/语言/关于）的逻辑与顺序。
- 不新增依赖、不改后端逻辑。

## 影响与风险

- 仅两处静态改动，无运行时状态变化。
- `main.go` 改动需要重新构建（`wails build`）才生效；前端改动随前端构建生效。
- 窗口宽度 1440 在常见外接屏/大屏笔记本逻辑分辨率内；若屏幕小于该宽度，macOS 会按屏幕自动收缩，最小宽度 800 兜底。

## 验收标准

1. `main.go` 中 `Width` 为 `1440`。
2. `AppHeader.vue` 中"设置"按钮为 `header-right` 最后一个子元素。
3. 前端构建通过（`npm run build`），Go 编译通过（`go test ./...`）。
4. （可选）重新打包 dmg 后启动，窗口宽度 1440、分栏显示正常，设置按钮位于竖排最底部。
