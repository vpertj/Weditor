# Weditor - 现代化 Markdown 编辑器

Weditor 是一款基于 Wails 框架开发的现代化 Markdown 编辑器，提供了丰富的编辑功能和优雅的用户界面，支持实时预览、所见即所得编辑、主题定制等特性。

## 🚀 主要功能

### 编辑功能
- **实时预览**：编辑 Markdown 内容时实时查看渲染效果
- **所见即所得（WYSIWYG）**：支持可视化编辑模式，无需记忆 Markdown 语法
- **Markdown 语法指南**：内置语法参考，帮助用户快速掌握 Markdown 写作
- **代码高亮**：支持多种编程语言的代码块高亮显示
- **Mermaid 图表支持**：直接在编辑器中创建和渲染 Mermaid 图表
- **丰富的工具栏**：提供常用编辑功能的快捷按钮
  - **标题**：一级标题、二级标题、三级标题
  - **文本格式**：粗体、斜体、删除线
  - **链接和图片**：插入链接、插入图片
  - **代码**：行内代码、代码块
  - **列表和引用**：引用、无序列表、有序列表、插入表格
  - **其他**：分割线
- **滚动同步**：编辑区域和预览区域自动滚动同步
- **实时内容更新**：编辑内容实时保存和更新

### 主题与样式定制
- **多主题支持**：内置多种颜色主题，支持明暗主题切换
- **自定义主题**：可自定义编辑器的颜色方案
- **字体设置**：支持调整字体类型和大小
- **代码样式**：可选择不同的代码高亮样式
- **间距调整**：自定义编辑器的行间距和段落间距
- **主题系统**：支持不同的主题系统（如 Breeze 和 Default）

### 用户体验
- **响应式设计**：适配不同屏幕尺寸
- **返回顶部按钮**：长文档编辑时快速返回顶部
- **通知系统**：操作反馈和提示
- **国际化支持**：支持中英文切换
- **剪贴板管理**：增强的剪贴板功能

### 编辑器特性
- **工具栏**：提供常用编辑功能的快捷按钮
- **设置面板**：丰富的配置选项，可自定义编辑器行为
- **浮动设置面板**：支持标签式设置界面
- **颜色选择器**：直观的颜色定制工具
- **下拉菜单**：便捷的功能访问方式

## 🛠️ 技术栈

### 后端
- **Go 语言**：高性能后端开发
- **Wails 框架**：跨平台桌面应用开发框架

### 前端
- **Vue.js 3**：现代化前端框架

## 📦 安装和运行

### 前置要求
- Go 1.18+（用于后端开发）
- Node.js 16+（用于前端开发）
- Wails CLI（用于项目构建）

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd Weditor
   ```

2. **安装依赖**
   ```bash
   # 安装前端依赖
   cd frontend
   npm install
   cd ..
   
   # 安装后端依赖
   go mod tidy
   ```

3. **开发模式运行**
   ```bash
   wails dev
   ```

4. **构建生产版本**
   ```bash
   wails build
   ```

## 📖 使用指南

### 基本编辑
1. 在左侧编辑区域输入 Markdown 内容
2. 右侧实时显示渲染效果
3. 可切换到 WYSIWYG 模式进行可视化编辑

### 主题定制
1. 点击右上角设置按钮打开设置面板
2. 选择「颜色主题」标签页
3. 从预设主题中选择或自定义颜色
4. 调整字体、代码样式和间距

### 使用 Mermaid 图表
1. 在编辑区域输入 Mermaid 代码块
   ```mermaid
   graph TD;
       A-->B;
       A-->C;
       B-->D;
       C-->D;
   ```
2. 渲染后将显示交互式图表


### 代码高亮
1. 在编辑区域输入带语言标识的代码块
   ```javascript
   function hello() {
       console.log("Hello, Weditor!");
   }
   ```
2. 渲染后将显示对应语言的语法高亮

## ⚙️ 配置选项

### 编辑器设置
- **字体类型**：选择编辑器使用的字体
- **字体大小**：调整编辑区域的字体大小
- **行间距**：设置行与行之间的间距
- **段落间距**：设置段落之间的间距

### 主题设置
- **颜色主题**：选择预设主题或自定义颜色
- **代码样式**：选择代码高亮样式
- **主题系统**：切换不同的主题系统

### 界面设置
- **语言**：切换中英文界面
- **通知**：开启或关闭通知提示
